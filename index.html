从物理布样采集到数字化归档的完整闭环

拒绝割裂的脚本拼接与零散的中间文件夹。每一次图像采集、主色分割、光源色貌测试与局部换色，都在统一工作流与 SQLite 账本下可追踪、可复现。

  1. 01 采集与导入

    单图 / 批量 / Nikon 联机

    支持单张与文件夹批量导入，内置 Nikon D7500 实时取景与三档预览分辨率直采入库，全链路执行 ICC → sRGB 色彩归一化。

  2. 02 提取与分割

    纯色与花纹双策略识别

    支持 auto / solid / pattern 面料识别，在 mean_shift 与 pattern_texture 分割间自适应切换，输出 mask、cluster、overview 与 Excel。

  3. 03 检索与色貌

    CIEDE2000 & CIECAM02

    将真实样本颜色锚定至感知均匀色空间，支持四大标准色库对照与六种 CIE 15:2004 标准光源下的正反向色貌推演。

  4. 04 换色与归档

    纹理换色与 SQLite 留痕

    结合 CatBoost 纹理标准差预测与三模式 mask 局部换色，所有输出图像、manifest 与任务历史自动持久化并支持原子备份恢复。

EIGHT INTEGRATED WORKBENCH MODULES

  • 20 步撤销 / 重做
05 纹理重染

面料数据库 & 批量预览任务

收录平纹、缎纹正反面、斜纹正反面五类实验织物纹理；通过 CatBoost 回归模型预测换色后纹理标准差，支持面料组 / 配色组最多 200 项批量任务与 8 图同屏比对。

  • CatBoost 纹理模型
  • 面料组 / 配色组批量
  • 8 图全屏对照

  • 227 款内置白模
  • 11 类服装分类
  • 500 张批量导入
07 局部重染

分割与换色工作台

自动承接样本原图与 mask_*.png 掩码，提供标准换色、分步迭代换色与有序多色换色三种模式，完整保留织物明暗层次与结构肌理。

  • 标准 / 分布 / 多色三模式
  • Mask 自动联动
  • 输出 Manifest 留痕

结果管理 & 数据保护
